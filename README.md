# Теплова лабораторія: місія дослідника

Інтерактивна навчальна гра з фізики для 8 класу.

## Запуск

Гра опублікована через GitHub Pages:

https://dmytro-rusnak-physics.github.io/physics-8-grade-thermo-lab/

## Збереження результатів

Завершені лабораторні роботи зберігаються локально в браузері через `localStorage` під ключем `thermoLabResultsV1`.

У журналі вчителя доступні:
- пошук за прізвищем, ім'ям або класом;
- фільтр за лабораторною роботою;
- перегляд повного звіту з відповідями, спробами, висновками, параметрами та результатами дослідів;
- експорт усіх записів у JSON (резервна копія);
- експорт таблиці у CSV;
- імпорт JSON-архіву з іншого пристрою;
- видалення окремих записів або всього локального журналу.

### Важливо про приватність

Результати учнів **не записуються в GitHub-репозиторій** і не надсилаються на сервер. Вони зберігаються лише в браузері та на пристрої, де учень виконав роботу.

Локальний журнал не синхронізується автоматично між комп'ютерами, браузерами або профілями. Для перенесення результатів на комп'ютер учителя:
1. на пристрої учня відкрий «Журнал учителя»;
2. натисни «Експорт JSON»;
3. передай файл учителю без публікації у відкритому репозиторії;
4. на комп'ютері вчителя відкрий журнал і натисни «Імпорт архіву».

Зберігай резервні JSON-файли в приватному місці. Очищення даних сайту або сховища браузера може видалити локальний журнал.

## Технології

- HTML, CSS та JavaScript без зовнішнього бекенду;
- GitHub Pages для публікації гри;
- браузерне локальне сховище для результатів.
