# Підключення «Теплової лабораторії» до Google Sheets

Гра надсилає окремий звіт після завершення кожної лабораторної роботи. У звіті зберігаються дані учня, відповіді на теорію, кількість спроб, результати всіх трьох експериментів, розрахунки, висновок і оцінка.

## 1. Створи Apps Script-проєкт

1. Увійди в потрібний Google-акаунт учителя.
2. Відкрий https://script.google.com/home/projects/create
3. Відкрий файл `Code.gs` у цьому репозиторії: https://github.com/Dmytro-Rusnak-physics/physics-8-grade-thermo-lab/blob/main/google-apps-script/Code.gs
4. Скопіюй увесь код у редактор Apps Script замість початкового вмісту.
5. Збережи проєкт.

## 2. Створи таблицю

1. У списку функцій вибери `setup`.
2. Натисни **Run / Виконати**.
3. Під час першого запуску Google попросить надати дозволи на створення та редагування таблиці — підтверди їх.
4. Відкрий **Execution log / Журнал виконання**. У ньому буде URL створеної Google-таблиці.
5. Таблиця матиме три аркуші:
   - **Результати** — один підсумковий рядок на кожну завершену лабораторну;
   - **Відповіді** — окремі відповіді учня на теорію, розрахунки та контрольні запитання;
   - **Досліди** — параметри й результати кожного експерименту.

Не вмикай публічний доступ до самої таблиці. Залиш її доступною лише своєму Google-акаунту та тим особам, яким ти свідомо надаси доступ.

## 3. Опублікуй приймач результатів

1. Натисни **Deploy → New deployment**.
2. Тип розгортання — **Web app**.
3. **Execute as** — **Me**.
4. **Who has access** — **Anyone**. Це потрібно, тому що учні надсилатимуть результати з відкритої GitHub Pages без входу в твій Google-акаунт.
5. Натисни **Deploy** та підтверди дозволи.
6. Скопіюй URL вебзастосунку, який закінчується на `/exec`.

Вебзастосунок приймає лише POST-звіти та не надає учням читання таблиці. Але його URL буде в коді відкритого сайту, тому технічно сторонні користувачі також зможуть надсилати записи. Не зберігай у звітах чутливі персональні дані; за потреби заміни ПІБ учнів на навчальні коди. Не публікуй саму таблицю.

## 4. Заверши підключення гри

Надішли в чат скопійований URL `/exec`. Його потрібно буде вставити в константу `GOOGLE_SHEETS_WEB_APP_URL` у `index.html` та оновити GitHub Pages.

Після цього перевір роботу: пройди одну лабораторну як тестовий учень і переконайся, що в таблиці з’явився запис на аркушах **Результати**, **Відповіді** та **Досліди**.
